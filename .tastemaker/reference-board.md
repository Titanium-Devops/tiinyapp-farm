# Reference board

Created: 2026-09-12
Mode: Persuade (home), Read (install), Operate (submit, account), Experience (app page)
Design read: app catalog and installer for owners of a pocket AI device, mode Persuade into Operate, with a warm night-farm visual lane carried into tool pages, dials variance 6 / motion 3 / density 5 / art direction 8.
Dials: variance 6, motion 3, density 5, art direction 8

## Quality bar (inferred, not viewed this session)
- Playdate Catalog (Panic): every game is a product with cover art; the art carries the card, text captions it.
- Raycast Store: dense, scannable rows; one install action per row; monospace only for commands.
- Obsidian community plugins: install count and one line; the reader decides in two seconds.
- Homebrew formula pages: one command, the facts in a plain list, nothing decorative.
- Stripe docs: numbered steps with a terminal block each, copy buttons, quiet type.

## Borrow
- Palette/material: the approved hero painting -> midnight ground, amber lantern light as the one warm accent, cyan glow as the second accent, never both on one element.
- Type/hierarchy: Fraunces for names only (h1, app names), Nunito for everything else, mono for commands and hashes only.
- Layout/composition: Playdate -> art tile leads each catalog card; Raycast -> one action per row; Stripe -> numbered rows for install.
- Motion/interaction: Raycast -> instant, 150 ms state changes; one reveal on the catalog grid, nothing else.
- Asset language: the sprout mascot family: cel-shaded night scenes with cyan glow and amber lanterns; every app gets an icon and a header in that family.

## Avoid
- Uniform grey cards of equal weight (the current site).
- Farm nouns in instructions.
- Three-column grids for sequential content.
- Empty grey placeholders where art belongs.

## Direction contract
- Thesis: a small device deserves a catalog that feels like a shelf of little products, and a tool that gets out of the way once you pick one.
- First viewport: hero painting as is; below it the shelf: art-led app tiles, name, one line, Install.
- System: tokens from the hero; Fraunces + Nunito + mono; 4 px scale; hairline separation on tool pages, tint alternation nowhere; one icon set (Tabler).
- Risk: art without discipline turns the tool pages into a picture book; the app page must stay a spec sheet with one picture.
