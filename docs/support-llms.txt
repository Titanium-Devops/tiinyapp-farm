# tiinyapp.farm support

> Help for the reviewed catalog and command-line tool that installs, starts, updates and removes apps beside a person's Tiiny.

If you are an AI agent helping a person, read the agent support procedure first. Diagnose the problem, draft the request, and have the person submit it. Start every support draft with `Drafted with <tool> (AI agent)`.

## What the farm is

tiinyapp.farm is a reviewed catalog of small apps. The farm CLI installs and runs those apps on the person's own computer beside their Tiiny, and the public API supports accounts, publishing, catalog activity and release checks.

## Security and privacy

Never include a Tiiny API key, a farm token, an email sign-in code, an archive containing secrets, recipient addresses, or private app data in a support request. The permissions guide explains the archive scanner and the agent guide explains how credentials are handled.
