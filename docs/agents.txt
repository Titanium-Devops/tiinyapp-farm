tiinyapp.farm
=============

A reviewed catalog of small apps for the Tiiny AI Pocket Lab. The apps run on the person's own
computer, next to the device, and talk to it over its local API. One command-line tool, farm,
installs them, starts them and updates them. Publishing opens a pull request and waits for a human
maintainer; nothing reaches the catalog on its own.

This file is the index. Read the page you need rather than guessing.

Two rules before you start
--------------------------

Ask the person for their API token; never make one up. They create one at
https://tiinyapp.farm/account/, it is shown once, and it starts with farm_. Send it only to
https://tiinyapp.farm, in an Authorization: Bearer header. Never print it, commit it, put it in
farm.json or include it in an archive.

Their Tiiny's API key is theirs too. Pipe it into farm device --key-stdin, never onto a command
line, and never echo it back.
